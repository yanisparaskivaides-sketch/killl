# Grand Mobile Kill-List Bot 5.0.0

Discord-бот для килл-листа и составов ОПГ Grand Mobile (сервер 15).

## Возможности

- Импорт логов убийств и защита от повторяющихся событий.
- Составы Тамбовской, Ореховской, Курганской и Кавказской ОПГ.
- Рейтинги, фильтры по мероприятиям, графики и отчёты.
- Интерактивное меню Discord.
- Необязательная интеграция AI через OpenRouter.
- JSON-хранилище с атомарной записью и резервными копиями.

## Требования

- Python 3.11 или новее, совместимая версия `discord.py` и установленные зависимости.
- Постоянное хранилище файлов на хостинге, если необходимо сохранять данные между перезапусками.
- Discord bot token. Для AI дополнительно нужен OpenRouter API key.

## Запуск локально

1. Распакуйте проект.
2. Создайте виртуальное окружение: `python -m venv .venv`.
3. Активируйте его и установите зависимости: `python -m pip install -r requirements.txt`.
4. Скопируйте `.env.example` в `.env` и заполните `DISCORD_TOKEN`.
5. Запустите: `python -m bot.main`.

Не добавляйте `.env` в Git и не публикуйте токен. Если токен случайно попал в архив или чат, отзовите его в Discord Developer Portal и создайте новый.

## Развёртывание на Plaged

1. Создайте Python-сервис/бот-процесс в панели Plaged.
2. Загрузите содержимое релизного архива без `.git`, `node_modules`, кэшей и локальных секретов.
3. Выберите Python 3.11+ (конкретную версию — из доступных в панели и совместимых с зависимостями).
4. Установите зависимости командой `python -m pip install -r requirements.txt`.
5. Укажите стартовую команду `python -m bot.main`.
6. Добавьте `DISCORD_TOKEN` в переменные окружения панели. Не записывайте токен в исходники.
7. Убедитесь, что каталог данных постоянный. При необходимости задайте `BOT_DATA_DIR` и `BOT_BACKUP_DIR` абсолютными путями, разрешёнными хостингом.
8. Запустите процесс и проверьте консольные логи и подключение бота в Discord.

Названия настроек и доступность постоянного диска зависят от конкретной панели Plaged; перед эксплуатацией проверьте их в документации/интерфейсе хостинга. Этот архив подготовлен для запуска как обычный Python-процесс, но сам по себе не выполняет вход в аккаунт Plaged и не развёртывает проект автоматически.

## Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `DISCORD_TOKEN` | Да | Токен Discord-бота |
| `OPENROUTER_API_KEY` | Нет | Включает AI-функции |
| `OPENROUTER_MODEL` | Нет | Модель OpenRouter |
| `DISCORD_GUILD_ID` | Нет | ID сервера для интеграций, которые его используют |
| `BOT_DATA_DIR` | Нет | Каталог рабочих JSON-файлов |
| `BOT_BACKUP_DIR` | Нет | Каталог резервных копий |
| `LOG_LEVEL` | Нет | Уровень журналирования |

## Данные и резервные копии

Рабочие данные находятся в `bot/data/`, резервные копии — в `bot/backups/` по умолчанию. Не удаляйте эти каталоги при обновлении. Перед заменой версии остановите процесс и скопируйте оба каталога в безопасное место. На хостинге с временным диском настройте внешний способ хранения резервных копий.

## Обновление

1. Остановите бота.
2. Скопируйте каталоги данных и резервных копий в безопасное место.
3. Замените код новой версией, не перезаписывая пользовательские данные.
4. Установите зависимости.
5. Запустите бота и проверьте логи, команды и данные.
6. Если запуск не удался, остановите процесс и верните предыдущий код вместе с резервной копией данных.

## Проверки

Запуск тестов: `python -m unittest discover -s bot/tests -v`.

## Безопасность релиза

В релиз не должны попадать `.env`, токены, локальные базы/данные, `bot/backups/`, `.git/`, `.venv/`, `node_modules/` и кэши. Доступность команд управления зависит от прав Discord-пользователя и настроек самого сервера.
